# Code of Conduct

Orbitgate follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and constructive; harassment and personal attacks are not tolerated, in issues, pull requests, discussions or any other project space.

## Reporting

Report unacceptable behaviour privately to the maintainers listed in [MAINTAINERS.md](MAINTAINERS.md), for example via a direct message on GitHub. Reports are handled confidentially. Maintainers enforce this code following the Contributor Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
